Giới thiệu dự án

Đây là website giới thiệu cho dự án Weather Chatbot with Interactive Map. Hệ thống cho phép người dùng tra cứu thời tiết hiện tại, tương tác với chatbot, xem bản đồ thời tiết nhiều lớp và dự đoán nhiệt độ bằng mô hình Machine Learning.

Tính năng chính

  • Chatbot hỏi đáp thời tiết theo tên thành phố hoặc câu lệnh tự nhiên
  • Hiển thị thông tin thời tiết như nhiệt độ, độ ẩm, áp suất, tốc độ gió
  • Bản đồ thời tiết tương tác với nhiều lớp hiển thị
  • Dự đoán nhiệt độ dựa trên mô hình Machine Learning
  • Dashboard phân tích dữ liệu thời tiết

Công nghệ sử dụng

  • Python, Streamlit
  • HTML, CSS
  • GitHub Pages, Netlify, InfinityFree
  • Machine Learning, Weather API, Interactive Map
